# VoxelSniper for Pumpkin

This crate is planned to be an implementation of the VoxelSniper plugin for the [Pumpkin](https://github.com/PumpkinMC/Pumpkin) Minecraft server.

## Current Status

This plugin is **not yet implemented**.

## Usage (When Implemented)

1.  Build the project using `cargo build --release`.
2.  Copy the generated library file (e.g., `libvoxelsniper.so`, `voxelsniper.dll`) from the `target/release` directory to your Pumpkin server's `plugins` directory.
3.  Start the Pumpkin server.

## Future Development

Development has not yet started. The goal is to implement the core features of VoxelSniper. Contributions and ideas are welcome for when the project kicks off.
